1   Product Import

Import products from Magento, match stock by location and categories, then export them to Wolt.

How to use this page

Step 1A: Export products from Magento

In Magento, navigate to:
System > Export > Entity Type > Products

Step 1B: Export Inventory Valuation from LS Retail

In LS Retail, navigate to:
LS Retail > Inventory Valuation
Apply the Location Filter, choose the required store, and export as a Microsoft Excel Document (Data & Layout).

Set the Stock Threshold

Select the threshold you want. For example, if you enter 3, only products with a stock quantity of 3 or more will be marked as True (Enabled).

Step 1C: Update product categories (optional)

In LS Retail, navigate to:
LS Retail > Configuration Packages > Item Hierarchy > 10000922 > Export to Excel

2   Wolt Stock Updater

Update the stock quantities and prices on your Wolt listing using data from Wolt, LS Retail, and Magento. This process updates the stock quantities from LS Retail while matching them with your latest Wolt stock export.

How to use this page

Step 2a: Wolt Current File — Export the current Wolt listing

In Wolt, navigate to:
Wolt > Listing Manager > Export to Google Sheets
Export the following fields only:

  • merchant_sku
  • inventory_total
  • enabled

Step 2b: Upload Stock Export from LS Retail

LS Retail > Inventory Valuation
Apply the Location Filter, choose the required store, and export as a Microsoft Excel Document (Data & Layout).

Step 2c: Export product prices from Magento (optional)

Magento > System > Export > Entity Type > Products

Set the Stock Threshold

Select the threshold you want. For example, if you enter 3, only products with a stock quantity of 3 or more will be marked as True (Enabled).

3   Check Stock

Find products that are in your stock export but are not yet listed on Wolt. This process compares your stock export with the list of Merchant SKUs currently available on Wolt and displays only the products that are not listed.

How to use this page

Step 3a: Upload Wolt Stock Export

Upload the files generated in the 1A Product Import process:

  • Magento Product Export
  • LS Retail Inventory Valuation

Note: Do not import the category file.

Step 3b: Upload Merchant SKU List — Export the Wolt Merchant SKU list

In Wolt, navigate to:
Wolt > Listing Manager > Export
Export Merchant SKU only.
